6L Sniper
=========
1. Double-click 6Lsniper.exe
2. Create account or log in
3. Account -> redeem your license key
4. Save your recovery key

FREE vs PAID
------------
FREE (no key):
  - Create account, log in, view settings
  - CANNOT scan or save results

PAID (active key):
  - All scan modes (custom, barcodes, combos, letters, single check)
  - Start / pause / stop sniping in the app
  - Available names -> available\ folder + on-screen results
  - Taken names cached + cloud sync
  - Quick login
  - See time left on subscription (or Lifetime)
  - Recovery key: switch up to 3 times

KEY TYPES: | 1 week | 1 month | Lifetime
Do not share your key - sharing can ban your account.

FOLDERS (do not delete)
-----------------------
available\         - found usernames (paid scanning)
taken usernames\   - taken cache
